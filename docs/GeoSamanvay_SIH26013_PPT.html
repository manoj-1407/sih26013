What Makes GeoSamanvay Different Four Core Ideas
① PROVENANCE-AWARE INDEPENDENCE
4 datasets · but only 2 independent origins. The DFS lineage graph counts origins, not files.
ORIG-1999 ──▶ Cadastral
└──▶ Revenue/RoR ← same = 1 lineage
ORIG-2022 ──▶ Municipal GIS ← lineage 2
ORIG-2024 ──▶ Drone ORI ← lineage 3
Result: 3 independent, not 4 sources
② EVIDENCE-WEIGHTED PROPOSAL
Not averaging. Not snapping. Smallest defensible change using quality-weighted reference + constrained adjustment.
Cadastral UNCHANGED (w=0.80)
Revenue/RoR UNCHANGED (w=0.75)
Municipal −0.8m adj (w=0.70)
Drone 2024 REFERENCE (w=0.90) ←
Every adjustment is documented with reason + weight
③ RIPPLE-EFFECT VALIDATION
93% confidence is not enough to auto-approve if the proposed change breaks surrounding features.
P-1041 ✓ unaffected
P-1043 ✗ 0.31m² overlap introduced
Building ✗ 2.1m² outside new boundary
Road ROW ✓ unaffected
→ REVIEW REQUIRED (confidence alone cannot override topology)
④ SIGNED EVIDENCE PACKAGE
Every decision is Ed25519 signed and independently verifiable. No server call needed to audit a past decision.
source_manifest.json ← SHA-256 all records
conflicts.json ← full taxonomy
confidence.json ← per-signal breakdown
decision.json ← officer + timestamp
Ed25519 signature ← independently verifiable
Original data never overwritten · fully reversible
