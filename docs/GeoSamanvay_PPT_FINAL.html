One parcel.
Four answers.
No way to know which to trust.

India's land records span cadastral surveys, revenue registers, municipal GIS, drone ORI, and satellite imagery — each maintained by a different agency, in a different CRS, updated at a different time. When they disagree about the same parcel, the current answer is: "check manually."

The naive approach

"Snap everything to the drone boundary." — Destroys source records, creates unjustified changes, no audit trail.

The status quo

"Check manually." — Officer opens four files, makes a judgement call, no verifiable evidence for that decision.

What's needed

Trace which sources are genuinely independent. Detect conflicts. Check downstream impact. Human approves. Decision is verifiable forever.

Solution

GeoSamanvay — Evidence-Aware Geospatial Reconciliation

Not a GIS editor. Not an auto-fix system. A reconciliation layer that sits between raw multi-source data and the authoritative record — tracing provenance, detecting conflicts, checking ripple impact, and producing a cryptographically auditable decision.

Core principle

Never overwrite source records.

Every original record is preserved immutably after ingest. Every proposed change is a new version, not an edit to the source.

AI proposes. Rules constrain. Human authority decides.

The matching engine suggests candidate matches. Deterministic topology gates constrain what can be auto-approved. The officer owns the final decision. The signed evidence package records it permanently.

Cryptographically Verifiable Decisions

Every approved decision is Ed25519-signed. Verification is stateless — no server, no database, no internet. A field officer in 2035 can verify a 2026 decision from a downloaded ZIP.
